# Лекториум — ИНИС, лабораторная работа №2

React-приложение (Vite) для магазина онлайн-курсов «Лекториум». Реализует компоненты из дизайн-системы ЛР1: кнопки «В корзину» / «Купить сейчас», карточка товара, селектор количества, иконка корзины.

Автор: Максимович Р. А., гр. 310101, БГУИР.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173.

Дополнительно: `npm run build` — сборка, `npm run lint` — проверка кода.

## Структура

```
src/
  assets/            SVG-ассеты из ЛР1 (логотип, иконка корзины, превью курса)
  components/
    Button/          кнопка (variant, disabled, onClick)
    CartIcon/        иконка корзины со счётчиком (count)
    ProductCard/     карточка товара (useState: quantity)
    QuantitySelector/ селектор количества (value, min, max, onChange)
    Logo/            логотип
  App.jsx            состояние корзины (useState: cartCount, message)
```

## Особенности

- Только функциональные компоненты и хук `useState`, без внешних библиотек состояния.
- Данные передаются через props, типы проверяются `PropTypes`.
- Стили инкапсулированы через CSS Modules, цвета — в CSS-переменных `src/index.css`.
